# Brookview Industries — website concept

Static site (HTML/CSS/JS, no build step) for Brookview Industries, precision trailer wiring in Milverton, Ontario.

- `index.html` — page content
- `styles.css` — styles
- `main.js` — Three.js scroll-driven 3D trailer tour (loaded from jsDelivr via import map)

Deploy: any static host. On Vercel, import the repo with framework preset "Other".
